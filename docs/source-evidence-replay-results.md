## Reconstruction and comparison

The existing records supplied **99 exact answer-and-evidence versions across 88
posts**, carrying 105 terminal human judgments. The merged version-level labels
are 78 ready, 18 repair and 3 unclear.
Explicit revisions supersede their ancestors; independent judgments and exact
notes remain preserved. Earlier admission-only judgments do not become answer
labels. One animated image remains a declared hold rather than being replaced
with a convenient frame. No new annotation round was required.

These are previously exposed development examples, not an unseen test set or a
population sample. Ten posts have multiple versions, including three versions
for one post. There are 86 currently known image/joke groups. Results across
versions, copies and earlier repeated checks are correlated.

Seven verified historical caches contributed 379 exact-input trials for 51
versions. The closest comparison is 51 first checks by GPT-6 Luna using the
previous SIMPLE interface: 49 development and two fresh-run records. Ten saved
development repeats remain variability evidence, not extra independent examples.
Other models and interfaces are retained as descriptive history. No baseline
was regenerated or chosen because its verdict looked favorable.

The new run freezes **98 original-evidence calls plus 14 external-evidence calls**,
using one shared $1 allowance. It changes the evidence rule, prompt and output
schema together, and increases the output allowance from 2,400 to 3,200 tokens.
Its difference from SIMPLE cannot be attributed solely to deleting the number
three. External pairs use the same new interface, with the source overlay as the
changed input. Both calls are independent draws, so a paired difference alone
does not establish causation.

## Reference coverage

The frozen research selection contained 23 posts with existing reference leads;
18 had reconstructable answer labels. Thirteen inspected text references cover
10 of those posts and 14 answer versions. The sources include two researched
Know Your Meme entries, reference articles, biographical accounts and an
attributed news interview. Passages state their limited scope and shared source
lineage. No linked video was treated as watched, and an inaccessible or
uninspected link supplied no corroborating passage.

The overlay was written before new verdicts. It is a newly retrieved evidence
condition, not a claim that the original human reviewers saw those passages.
Human answer labels do **not** provide gold labels for source sufficiency.
The initiating `1uis49b` observation remains a policy example, not an invented
answer-quality label in the evaluation.

Of the 14 external-evidence pairs, **nine have valid responses in both arms**.
None changes answer quality, evidence status or the combined verdict. Five pairs
have a validation failure in one or both arms; there are no missing calls. The
valid pairs include correlated versions of the same post. Sources often confirm
references already present in comments, and human source-sufficiency labels are
absent. This small selected comparison is inconclusive about the benefit of
external references; it neither validates automatic KYM authority nor shows that
retrieval is unhelpful.

## Decision and remaining limits

The hypothesis required useful recovery without known-answer regressions or
misses. That standard is not met. The evidence-policy objection is supported by
three directly inspected count-only holds, while this checker remains unreliable
at deciding which details are essential and whether competing readings matter.
A source supporting a reference cannot repair an incomplete candidate answer by
itself. The added claim schema also needs engineering work before it is suitable
for unattended use.

Use the completed reconstruction and report as the reusable comparison base.
For curation, assess support for the image, essential reference and this-instance
connection; use researched references as inspectable evidence, with human
judgments still authoritative. Keep automatic admission unqualified. Further
work should address that broader reliability problem rather than automatically
running another prompt variant on these same exposed cases. This milestone
requires no new labels, collection, answer rewriting or production migration.
